# Vertical 3:4 Layout Skill

This skill is the layout source of truth for `vertical-3-4` pages, usually 1200x1600.

A 3:4 canvas is a poster-like vertical presentation page. It has more width than 9:16, so it can support compact two-column pockets, but it still needs a vertical reading path and a strong focal hierarchy.

## Use this skill when

- The selected slide size is `vertical-3-4`
- The prompt says the canvas is 1200x1600 or 3:4
- Creating, relaying out, or repairing a vertical poster-style page

## Composition

Good structures:

- strong title block + main visual/data zone + evidence band
- hero metric plus explanation rows
- compact two-column evidence inside one vertical section
- vertical process with grouped subpoints
- poster claim + proof modules
- comparison rows with aligned labels

Avoid:

- long stacks of equal cards with no focal point
- wide PPT dashboard rows
- three equal columns
- tiny text tables
- top-heavy pages with unused bottom space

## Rules

- Keep one visual or conceptual anchor larger than the rest.
- Use vertical sections, but group small facts into bands/chips so the page does not become a long list.
- Body text stays at least 18px; headings stay at least 24px.
- Use current canvas dimensions from the prompt, never 1600x900 defaults.
- A compact two-column subgrid is allowed only when each column remains readable.
- Charts should be one clear object, with a visible interpretation sentence.

## Repair checklist

- If the page is just a stack of cards, introduce a hero/focal block.
- If it feels like a cropped 16:9 slide, rebuild around vertical poster hierarchy.
- If the bottom is empty, add a conclusion, evidence band, or summary row.
